## 坑1：视频质量不足导致广告亏损

| 项目 | 内容 |
|:---|:---|
| **日期** | 2026-05-26（复盘发现） |
| **场景** | W12 周度复盘，视频渠道分析 |
| **操作** | 大量铺量生产视频（706条），但未把控视频前3秒的质量 |
| **后果** | 2秒播放率仅 5.5%（基准 25%），6秒播放率仅 1.9%（基准 15%），广告 ROI 仅 0.19x，严重亏损 |
| **原因分析** | 追求数量忽视质量，视频开头缺乏强钩子；达人缺乏脚本指导，自由发挥质量参差不齐 |
| **预警信号** | 当 2 秒播放率持续低于 15% 时，应立即启动视频质量审查 |
| **改进方案** | 1. 建立视频前3秒钩子模板库（价格对比/效果展示/悬念提问）<br>2. 给达人提供标准化的脚本框架，而非完全自由发挥<br>3. 对持续 2 周无产出的视频暂停广告投放 |

## 坑2：曝光增长≠GMV增长（Sunglasses 案例）

| 项目 | 内容 |
|:---|:---|
| **日期** | 2026-05-26（复盘发现） |
| **场景** | W12 周度复盘，Sunglasses 商品分析 |
| **操作** | 增加 Sunglasses 的视频投放量，曝光从 5,482 → 11,625（+112%） |
| **后果** | GMV 反而下降 25.3%（₱2,476 → ₱1,850），转化率从 1.87% 暴跌至 0.62% |
| **原因分析** | 盲目增加曝光但未优化转化链路；视频内容可能触达了非精准人群；商品详情页或价格缺乏竞争力 |
| **预警信号** | 当曝光增长超过 50% 但转化率下降超过 30% 时，应立即暂停投放并排查原因 |
| **改进方案** | 1. 先优化商品详情页（佩戴效果图、尺寸说明、材质描述）<br>2. 调整视频 CTA，增加限时优惠信息<br>3. 重新定位目标人群，避免流量浪费 |

## 坑3：零数据商品积压严重

| 项目 | 内容 |
|:---|:---|
| **日期** | 2026-05-26（复盘发现） |
| **场景** | W12 周度复盘，商品总览分析 |
| **操作** | 持续上架新品（W12 新增 5 款），但未对老品进行清理 |
| **后果** | 21 款在售商品中 17 款零出单（81%），动销率仅 19% |
| **原因分析** | 缺乏商品生命周期管理机制，上架后无跟进推广；部分商品缺乏差异化优势 |
| **预警信号** | 当动销率连续 2 周低于 30% 时，启动商品清理流程 |
| **改进方案** | 1. 建立商品 ABC 分类管理机制（A 类重点推、B 类测试推、C 类清理下架）<br>2. 每周评估零数据商品，连续 3 周零出单的自动标记为待清理<br>3. 控制每周上新数量（建议 2-3 款），确保每款新品有足够的推广资源 |

## 坑4：忽视"改变主意"退货双向运费新规

| 项目 | 内容 |
|:---|:---|
| **日期** | 2026-05-29（学习行业知识库发现） |
| **场景** | 共性杀机：东南亚退货政策变化（2026年4月20日生效） |
| **操作** | 未将退货风险成本纳入定价计算 |
| **后果** | 低价品（≤₱150）退货运费可能吃掉全部利润，低客单饰品退一单亏一单 |
| **原因分析** | 定价SOP中保本价公式未包含退货风险成本；未为低价品开启"仅退款不退货"功能 |
| **预警信号** | 当退货率>5%且客单价≤₱150时，应立即检查退货成本和利润是否倒挂 |
| **改进方案** | 1. 更新保本价公式：**保本价 = 成本 + 佣金 + 运费 + 包装 + 退货风险成本**<br>2. 低价品（≤₱150）启用"仅退款不退货"功能<br>3. 每月检查退货率变化，动态调整定价 |

## 坑5：忽视SPS店铺体验分和AHR账号健康分

| 项目 | 内容 |
|:---|:---|
| **日期** | 2026-05-29（学习行业知识库发现） |
| **场景** | 平台规则升级：2026年5月推出AHR替代原有违规分机制；SPS成为流量分配核心指标 |
| **操作** | 未将SPS/AHR纳入日常监控，不知道店铺健康状态 |
| **后果** | SPS<4.0导致流量降权、失去活动报名资格；AHR<50分可能封号，无法及时预警 |
| **原因分析** | 数据分析SOP和复盘模板中缺乏SPS/AHR监控维度 |
| **预警信号** | SPS<4.0黄色预警 / SPS<3.5红色预警 / AHR<200立即检查违规记录 |
| **改进方案** | 1. 每日5分钟看板新增SPS/AHR监控<br>2. 每周复盘必须检查SPS/AHR变化<br>3. AHR<50立即处理违规并申诉<br>4. 确保发货时效（美区2天/东南亚48小时）维持履约评分 |

## 坑6：内容高度同质化导致达人降权

| 项目 | 内容 |
|:---|:---|
| **日期** | 2026-05-29（学习行业知识库发现） |
| **场景** | 达人合作管理：大量达人用同一脚本/同一角度带货同一商品 |
| **操作** | 给多个达人提供相同的脚本，同一商品短时间被多个达人反复带货 |
| **后果** | 平台算法检测到内容重复，降低所有相关视频的推荐权重，达人合作效果大打折扣 |
| **原因分析** | 缺乏达人内容差异化分配机制；同一商品的达人视频角度单一 |
| **预警信号** | 同一商品每周有>5个达人发布同类内容时，应预警内容同质化风险 |
| **改进方案** | 1. 每个达人分配不同的内容角度（开箱/佩戴/礼物/对比/搭配）<br>2. 达人视频发布时间错开（至少间隔2小时）<br>3. 一个达人视频爆了→其他达人暂缓该品发布<br>4. 建立达人内容排期表可视化管控 |
