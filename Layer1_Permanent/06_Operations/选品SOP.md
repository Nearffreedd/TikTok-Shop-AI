# 选品 SOP - TikTok Shop 东南亚

## 一、选品漏斗
1. **市场热度**：TikTok热词榜 / 商品榜持续3天上升
2. **竞争度**：头部3家月销<500单，利润空间>30%
3. **展示力**：15秒能讲出卖点（视觉化强）
4. **合规性**：无禁售/敏感/版权风险

## 二、评分权重（总分100）
- 近7日销量增速（30分）：环比>50%得满分
- 利润率（25分）：>35%得满分
- 视频爆款潜力（20分）：是否有自然爆款视频
- 供应链难度（15分）：货源稳定+一件代发
- 季节/节日相关性（10分）

## 三、爆款模式复制评估
> 当某个商品已验证了产品力和推广模型后，可快速复制到同品类其他商品

### 复制可行性评分（总分50分，作为选品加权分）
| 维度 | 分值 | 评分标准 |
|:---|:---:|:---|
| **已验证爆款** | 15分 | 店铺内已有同品类爆款（GMV>₱5,000/周）得满分 |
| **受众重叠度** | 10分 | 目标人群与现有爆款受众重叠>60%得满分 |
| **内容复用度** | 10分 | 现有爆款的视频模板/脚本可直接适配得满分 |
| **供应链协同** | 8分 | 与现有爆款同供应商/同材质得满分 |
| **价格带匹配** | 7分 | 定价在现有爆款价格带的±30%以内得满分 |

### 复制策略建议
| 复制类型 | 适用场景 | 操作建议 |
|:---|:---|:---|
| **1:1 复制** | 同品类、同价格带、同人群 | 直接复用已验证的视频模板和达人合作模式 |
| **微调复制** | 同品类、不同价格带/人群 | 调整视频脚本的钩子和卖点，达人策略微调 |
| **跨界复制** | 不同品类、同人群 | 保留达人合作模式，重新制作内容脚本 |

### 成功案例
- **Bible Bracelet (SL06)**：复制 Clover Set 的"视频驱动+达人合作"模式，GMV 环比 +91.9%
- **关键条件**：同品类（手链）、同人群（菲律宾女性）、同价格带（₱100-300）


## 三、推荐门槛
- 综合得分 ≥75 → 强烈推荐，立即上架测试
- 60~75 → 观察，补充数据
- <60 → 放弃
