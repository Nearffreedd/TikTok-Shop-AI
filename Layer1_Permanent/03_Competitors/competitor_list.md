## 添加新竞品

如需添加新竞品，请在此表格中新增一行，然后运行：
```bash
python scripts/competitor_tracker.py --add
```
或直接运行追踪命令自动识别新竞品：
```bash
python scripts/competitor_tracker.py --track "竞品名称"
```
