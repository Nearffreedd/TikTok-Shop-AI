## 三、竞品GMV估算方法（3种）

> TikTok不公开竞品GMV数据，需要用以下方法推算。

### 方法1：基于可见销量×均价（最常用）

```
估算GMV ≈ 商品卡可见销量 × 商品单价
```
- 商品卡可见销量：TikTok前台商品页显示的"已售X件"
- 商品单价：取商品SKU中间价
- 注意：此估算是下限（未计入达人链接的额外销量）

### 方法2：基于达人合作量估算

```
估算GMV ≈ 总达人合作数 × 平均达人单产
```
- 平均达人单产：菲律宾饰品参考₱500-2000/达人/月
- 注意：纯佣金达人产出一般低于商家自投

### 方法3：基于视频播放量反推

```
估算GMV ≈ 总视频播放量 × 行业平均CVR × 客单价
```
- 行业平均CVR ≈ 1-3%（饰品品类偏低端，按1.5%估算）
- 客单价按实际商品价格估算

## 四、竞品达人矩阵分析

> 通过分析竞品合作的达人结构，判断其增长模型。

| 分析维度 | 说明 | 数据来源 |
|:---|:---|:---|
| 合作达人数量 | 近30天总量 | 联盟后台/手动统计 |
| 达人粉丝分层 | 头部>100K / 腰部10-100K / 微型1-10K | 手动查看 |
| 达人类型偏好 | 时尚/生活方式/信仰/泛娱乐 | 内容观察 |
| Top达人分析 | 合作最多的5个达人 | 手动记录 |

**策略推断：**
```
大量微型达人(1-10K) → 走量策略，成本控制型
少量头部达人(100K+) → 品牌建设型，预算充足
大量腰部达人(10-100K) → 平衡策略，追求ROI最优
```

## 五、竞品广告策略推断

| 信号 | 推测 | 依据 |
|:---|:---|:---|
| 某视频持续出现推荐流 | 该视频在投GMV Max | 自然流量通常2-3天下降 |
| 多个视频同时出现同一品 | 多素材GMV Max | 自然流量很少同时爆 |
| 大促期视频量暴增 | 加大广告预算 | 大促期间广告配合 |
| 竞品视频突然消失 | 广告暂停/素材审核不通过 | 广告账户问题 |
